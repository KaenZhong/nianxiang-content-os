# 念响OS · 三平台接入

本包是同一套Skill，阿响入口和内容/保存契约不随平台复制。先试一份非敏感素材，再连接长期知识。下面区分官方资料说明、当前环境检查和实际任务测试；资料支持不等于账号已开通或本包已实测。

## Codex

导入后的安装阶段，让Agent读取并执行[私人目录初始化](../references/system/installation.md)：先扫描已有根，展示完整路径，首次确认后创建或复用并回读；这个步骤不等待飞书建库。桌面与云端分别检查当前运行环境的路径和持久性。

解压后将完整nianxiang-content-os目录放在所选项目的`.agents/skills/`。在该项目启动Codex，以`$nianxiang-content-os`显式调用；也可按描述自动匹配。若变更未出现，再重启。阿响的agent/AGENTS.md由Skill显式读取，不复制为项目根规则。用户级目录及仓库扫描方式以[OpenAI官方技能说明](https://learn.chatgpt.com/docs/build-skills)为准。

先说“写朋友圈，把下面经历写成稿，不加报名入口”，检查是否实际读取入口/人格/共创及渠道方法。无私人库仍可创作；有Python/文件/lark-cli且账户与对象授权完整时，再按[连接协议](../references/knowledge/connection.md)核验profile。原生飞书工具也须满足相同身份、对象、保存和回读契约，不能以平台名称推定可用。

本版本已验证Codex项目内加载、直接创作、选题与新会话任务恢复；测试使用合成资料和只读源适配。真实飞书账号和远端读写仍需核验。

## WorkBuddy

技能上传/启用后，让Agent先完成[私人目录初始化](../references/system/installation.md)。上传本身不会自动创建目录；实际探测文件能力，扫描已有根，首次路径确认后才创建。云端需确认持久位置，无文件能力时报告初始化待完成。

按[官方技能说明](https://www.codebuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Skills-Market)进入“添加技能→上传技能”，导入本地包并启用。此入口已按官方资料核对，本包导入、脚本执行及真实飞书读写尚未实测。

导入后先提供合成素材，确认阿响能读取包内方法。需要长期知识时检查当前会话实际提供的身份、Wiki/Docx/Base工具及版本/业务键回读能力；有Python与已认证lark-cli可用同一管理入口，只有原生工具时按同一业务契约操作。Python、本地目录、选择卡和异步答案工具都须实际探测，不根据安装成功宣称具备。

## 豆包工作

技能导入后先请求Agent按[私人目录初始化](../references/system/installation.md)检查并引导；实际有文件能力才扫描、确认和创建。没有文件系统时只报告公共Skill导入成功与目录未初始化，不承诺本地持久任务。

[飞书官方说明](https://www.feishu.cn/content/article/7677519271848610746)介绍本地技能导入及原生飞书文档、知识库、多维表格能力。通过当前客户端的技能入口导入本地文件，再在对话中指定念响；具体入口和企业权限以实际界面为准。本包导入和完整旅程尚未实测。

确认当前使用豆包身份还是飞书身份，再核验私人库账号和对象。能原生读写飞书时仍需目标、具体授权及回读；没有本地文件能力不承诺profile/tasks、派生摘要、持久pending或脚本更新。首次缺工具继续用当轮素材创作，说明未长期保存。

## 缺工具时

- 无私人库：用用户当轮事实与限制共创，不称已校准个人风格。
- 无Python、有原生飞书：读取并执行包内契约，实际核验字段；不报告运行了脚本。
- 无本地文件：当前会话可继续，跨会话只找回飞书已保存对象；未保存素材请用户补充。
- 无原生提问工具：给简洁文字选项并等真实回答；不伪造卡片、预选或回执。

反馈请提供平台/入口、版本、脱敏复现步骤、实际与预期结果。不要提交私人正文、账号token或完整profile。本包不内置认证密钥、第三方连接器或官方自动更新源。


## 使用触发的后台刷新

有持久本地文件与Python时按[同步协议](../references/system/synchronization.md)检查真实子进程能否脱离当前调用继续运行。默认本地读取，到期再启动worker；不依赖各AI平台定时任务。平台会杀掉子进程、无法执行Python或缺lark-cli时，不能报告后台完成，使用本地副本并给出实际刷新状态。无文件的原生飞书路径继续按需读取远端，不承诺相同缓存速度。
