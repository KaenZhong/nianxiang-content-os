# 念响AI · 选题地图与勾选

## 用途与阅读顺序

地图用于快速挑出愿意继续创作的题目。先用具体、能引起目标读者兴趣的标题吸引阅读，再提供判断所需的现场与依据；不先铺编辑报告、改版过程或内部统计。标题必须兑现素材中的真实判断，不能为了传播力放大事实。标题方向展示不同切入角度，不用口播开头代替选题价值。

批量素材按与当前内容策略的契合程度分级：

- 🔴 A 高度契合内容策略：直接支撑当前主线与目标受众的具体问题。
- 🟡 B 部分契合内容策略：有相关价值，需要收窄受众、调整切口或连接当前主线。
- 🟢 C 暂不契合内容策略：当前主线之外，或尚不能建立与当前目标的联系。

契合度不是是否优先考虑、素材成熟度、拍摄准备度或爆款预测。A 类也可能缺证据；把缺口写进判断，不因缺口直接降成 B。等级依据当前策略而变化，数量随素材，不强制三档都有题。每周从池中挑可创作内容时，另看素材与观点准备度，不能直接把 A 当作本周已能拍。

## 每题的信息量

- A 类：加粗复选框题号与标题 → 标题方向 → 当时发生了什么 → 💫 阿响的判断 → 来源。
- B 类：加粗复选框题号与标题 → 标题方向 → 现场简述 → 💫 阿响的判断 → 来源；信息量少于 A。
- C 类：加粗复选框题号与标题 → 精简标题方向 → 现场与判断 → 来源；说明现阶段为何不契合、什么变化值得重新考虑。

标题方向用分点展示所有有实质区别的方向，每点以切入角度命名，具体候选用《》包裹；有主推时，标注放在右书名号之后，写作 `切入角度：《具体标题》（主推）`，不写成 `《具体标题（主推）》`，也不把角度标签写成“主推”。不为数量生成同义标题。

还原现场要让用户不回到原资料也能理解来源：谁提出什么具体问题、怎样回答或推进、关键细节与原话。区分用户、他人和阿响推断；引语与忠实转述分清，不倒推现场或动机。每个说明板块通常 2—3 点，合并同一意思，不为排版切成过多碎点。

判断说明这题与策略、受众的关系，阿响推荐的表达价值及仍需校准的立场或事实；不展开完整脚本、视频开头、拍摄计划和发布运营。来源给真实可找回的文档位置或录音时间点；没有链接就保留可辨认线索，不制造链接。

## 飞书呈现与反馈

需要文档时提供地图内容与排版要求；统一流程读取当前可用文档能力的操作指引，按授权定位、写入和回读。先核对目标和最新正文；修改同一文档，保留用户改题、选择与配色。私人寻址按[连接与目标核验](../knowledge/connection.md)，普通文档使用用户指定或已约定目标。用户明确样例或本轮偏好优先。

- 开头用高亮块，简述本批主题与完整使用方式：勾选后可以继续共创，也可以直接选题入池；勾完告诉阿响再读取。有时间共创、无时间先入池，两者不互为前置条件。
- 保留完整 ABC 章节标题；分隔线紧接章节标题，标题与分隔线之间、分隔线与首题之间不插空段落。章节之前、相邻题目之间各留一个空白段落：上一题来源后留白，再放下一题复选框或下一章节标题。来源说明与首个章节之间、末尾补充章节之前也留一个空白段落；同一题内部不逐字段加空行。避免重复选题一览、迁移说明和版本调整说明。
- 每道题只设置一个复选框，题号与完整标题整行加粗；题号后的标题不加书名号。短编号只在本地图有效。
- A 红、B 橙、C 绿，章节圆点与题目字色一致。可用 rgb(216,57,49)、rgb(222,120,2)、rgb(46,161,33)；说明正文普通字色，字段标签加粗。
- 判断字段标签统一写作 `💫 阿响的判断：`，emoji 后保留一个半角空格，整条标签加粗。
- 写作者的经历与判断用已授权昵称或姓名；使用说明和面向观众的标题、正文按语境使用“你”，不机械替换。
- 格式微调优先行内修改，不为排版重建复选框或覆盖全文；写后回读加粗、颜色、选择、来源链接、题间与章前留白、判断标签的 emoji 后空格，以及所有 `（主推）` 是否位于 `》` 之后。

XML 选题行示例（颜色按等级，done 保留实际选择）：

```xml
<checkbox done="false"><b><span text-color="rgb(216,57,49)">A1　具体选题标题</span></b></checkbox>
```

用户说已选好时读最新勾选。已约定或明确要求入池则按[选题池契约](../knowledge/topic-pool.md)查重保存，否则按用户意图共创或返回选择；点击不自动唤醒 Agent。读写结果不确定先查实际状态，不重复创建。

## 交接创作

交接文档与短编号、当前策略、主要受众、核心判断及其已确认／候选状态、真实现场与来源、必须保留的表达、公开边界和待补事实，不只传标题。完整渠道稿不放进选题地图；对话出稿或另建文档依用户授权，保存遵循[作品契约](../knowledge/works.md)。
