# 念响OS · 安装与私人目录初始化

## 何时执行

安装念响包括导入公共Skill和初始化私人目录两个步骤。导入后，安装Agent立即执行本流程；只有完成目录扫描、必要的路径确认、创建或复用及回读，才报告“私人目录初始化完成”。平台上传Skill不会自动执行脚本：安装指引必须让Agent读取本文件并完成初始化。平台没有安装回调时，在导入后的首次加载先完成此步骤，不等到建库或首次保存时才偷偷创建。

已有有效初始化记录时扫描并复用，不反复询问、不重复建目录。既有目录尚无记录时说明完整路径和复用内容，确认后补初始化记录；不因此自动创建新账号配置档、迁移旧资料或连接飞书。

## 安装顺序

1. 检查本次Agent运行在本机还是云端，以及实际文件读写能力。目录属于运行环境的当前系统用户；云端路径不能写成本机电脑的路径。
2. 只读扫描显式指定路径、环境变量NIANXIANG_HOME、当前用户主目录下的.nianxiang，以及用户提供的其他旧私人根。去重后识别已有有效初始化记录或兼容profiles布局。不是全盘搜查，不读取私人正文。发现旧Skill的local资料只作为迁移来源，不能把Skill内部改作私人根。
3. 只有一个可复用根时推荐复用；多个已有根先展示完整路径和配置档数量，让用户选定。没有已有根时推荐当前用户主目录下的.nianxiang，或用户指定的包外私人目录。目录有无关内容、无效布局、重定向或非当前用户所有时停止，换位置或先处理冲突；不覆盖、不删原件。
4. 首次创建或首次接管已有目录前，展示**完整绝对路径、运行电脑/环境、保存内容和持久性**，等待真实确认。用户刚刚已经看过并明确确认同一路径时沿用该授权，不重复问。推荐、预选、沉默和笼统“安装技能”都不算目录确认。可以按[交互协议](interaction.md)提供“使用此路径”与“另选路径”。
5. 确认后在安装阶段创建缺失的目录，或复用已有目录；写入包外data-root.json，记录路径、环境、持久性依据及真实确认。回读核对实际路径、记录和目录读写能力。已有配置档保持原样，不自动激活。
6. 向用户报告实际完整路径、创建/复用结果，以及连接和旧资料迁移是否完成。初始化只负责目录；随后需要连接或迁移时按[连接协议](../knowledge/connection.md)单独执行。

## 用户确认说明

本机示例，路径必须替换为实际扫描结果：

> 念响需要一个私人资料目录。我建议使用当前电脑用户主目录下的 `{完整绝对路径}`。这里会保存连接配置、任务进度、待同步请求和可重建缓存；长期个人知识仍在你的飞书库。目录独立于Agent和Skill，更新技能时会保留。是否使用这个路径并创建目录？

复用示例：

> 找到已有念响私人目录：`{完整绝对路径}`，含 {数量} 个配置档。我会保留原资料并复用这个目录。是否使用它？

云端再说明目录位于哪台云端环境、持久卷/用户目录的实际依据、重启或销毁后已知的保留范围。无法确认持久性时，先让用户选择平台提供的持久位置；不把临时容器目录说成长期保存。跨Agent可复用同一可访问根；跨电脑不自动同步本地任务、pending或缓存，也不复制认证密钥。

## 脚本入口

由Agent在Skill根执行，用户无需手动拼路径或复制命令。扫描和预览不调用飞书、不创建私人根。预览文件放在包外临时位置，不能放到尚未确认的目标内。

```bash
python3 -B scripts/manage.py install scan
python3 -B scripts/manage.py install plan --environment local --output '<包外临时预览JSON>'
# 展示预览中的完整data_root，等待用户真实路径确认后：
python3 -B scripts/manage.py install apply --plan '<包外临时预览JSON>' --confirmed-path '<预览完整绝对路径>' --consent '<用户真实确认原话>'
```

需要选择其他位置时，在install前加 `--data-dir '<完整私人根>'`；用户提供旧根时scan/plan可加 `--known-root '<旧私人根>'`。多个已有根须用data-dir选定。后续管理命令使用返回的data_root；若与默认根不同，沿用显式参数或在当前环境配置NIANXIANG_HOME，不能忽略返回路径另建一份。

云端plan必须使用 `--environment cloud --persistence persistent-volume --evidence '<实际平台设置或挂载依据>'`。脚本只记录声明及依据，不自动配置云端卷，也不证明重启持久性；结果中的restart_tested=false必须如实保留。实际重启保留测试另行执行并报告。

apply重新检查目录是否变化；路径确认不匹配、预览过期、冲突或缺少真实确认时停止。profile create要求私人根已初始化，不能绕过安装阶段直接隐式创建根。首次新建目录权限限制为当前用户，记录不进入公共包。

## 无脚本或无文件能力

有文件能力但没有Python时，Agent按相同扫描、说明、确认、创建、回读流程操作，并写入相同data-root.json字段；不能声称运行了脚本。有文件能力但无法核验云端持久位置时，目录初始化待完成。

没有文件系统的平台说明“公共Skill已导入，私人目录尚未初始化”，不能宣称完整安装或承诺本地任务恢复。仍可使用本轮素材创作，或按可用原生飞书能力读取已保存知识。后来获得文件能力或更换运行环境时，再完成此流程。
